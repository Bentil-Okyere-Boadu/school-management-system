# Attendance

**Who can use this:** School Admin, Teacher, Student, Parent  
**Where:** School Admin → Attendance; Teacher → Classes → select class → Attendance; Student → Attendance; Parent → Family overview → Attendance tab

## Overview

Attendance lets schools track who was present or absent by class and date. Teachers record daily attendance for their classes. School admins review attendance sheets and summaries across the school. Students and parents can view attendance history for themselves or their wards.

## School Admin

| Action | Result |
|--------|--------|
| Open Attendance and select the **Attendance Sheet** tab. Choose a week, month, year, and class. | A read-only grid shows each student’s attendance status (present, absent, holiday, or weekend) for the selected period. |
| Switch to the **Attendance Summary** tab. Set a start date, end date, and class. | Summary cards show total, present, and absent counts plus an average attendance rate. A table lists attendance breakdowns for the selected class and date range. |

## Teacher

| Action | Result |
|--------|--------|
| Open **Classes**, select a class, and go to the **Attendance Sheet** tab. Choose week, month, or year. | A grid loads showing enrolled students and dates. You can tap a cell to mark a student present or absent (future dates cannot be changed). After marking absent, a success message appears and the grid refreshes. An attendance notification may be sent for absent marks. |
| Open the **Students** tab on the class page. | You see the enrolled students table. Clicking a student opens their profile. |
| Open the **Attendance Summary** tab. | You see a view-only attendance summary for the class. |

## Student

| Action | Result |
|--------|--------|
| Open **Attendance** and select an academic year. | Summary counts, percentages, and a daily attendance grid display for your record. This view is read-only. |

## Parent

| Action | Result |
|--------|--------|
| On the Family overview page, select a ward and open the **Attendance** tab. Change the month or year. | The ward’s attendance sheet updates for the selected period. |

## Empty, error, and blocked states

- School Admin and Teacher views show a loading indicator while data loads.
- If a class has no students, the attendance sheet shows “No students found.”
- The School Admin summary table may show “No users found” when there is no data for the selection.
