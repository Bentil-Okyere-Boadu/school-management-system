# Assignments

**Who can use this:** School Admin, Teacher, Student  
**Where:** School Admin → Scores; Teacher → Curriculum → Assignments tab; Student → My Scores

## Overview

Assignments let teachers create work for their classes, students submit files and notes, and teachers grade submissions. School admins can browse all assignments and view submission status across the school.

## School Admin

| Action | Result |
|--------|--------|
| Open **Scores** (Assignments). Search or filter by teacher, class, term, or curriculum. | The assignment table updates to match your filters. |
| Open **View Details** on an assignment from the row menu. | You see the assignment detail page with **Submitted** and **Pending** tabs showing which students have turned in work. |

## Teacher

| Action | Result |
|--------|--------|
| Open **Curriculum**, go to the **Assignments** tab, and filter by term or curriculum. | Your assignment list filters accordingly. |
| Create a new assignment with title, topic, class, due date, instructions, optional file, and publish toggle. | A success message appears and the assignment list refreshes. |
| Edit or delete an existing assignment. | Edits save with a success message. Deleting requires confirmation, then shows a deleted confirmation and refreshes the list. |
| Click **Grade** on an assignment. | You open the grading page with **Submitted** and **Pending** tabs. |
| On the **Submitted** tab, view a student’s submission. | A dialog shows the student’s file and notes. |
| Enter a score and feedback for a submitted assignment and save. | A success message appears and the row updates with the grade. |
| View the **Pending** tab. | You see a read-only list of students who have not yet submitted. |

## Student

| Action | Result |
|--------|--------|
| Open **My Scores**, go to the **Pending** tab, attach a file and/or add notes, and submit. | A confirmation dialog appears. After confirming, a success message appears and the assignment moves to **Submitted**. |
| View the **Submitted** tab. | You see assignments awaiting grading. |
| On the **Graded** tab, click **View Feedback** on an assignment. | A dialog shows your score, teacher feedback, and any attachment. |

## Empty, error, and blocked states

- School Admin and Teacher lists show “No assignments found” when empty.
- Submission tables show a loading indicator while data loads.
