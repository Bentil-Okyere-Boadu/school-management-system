# Notifications

**Who can use this:** School Admin, Teacher, Student  
**Where:** Notification bell in the header; School Admin → Notifications (full page)

## Overview

Notifications keep users informed about school activity such as admissions, attendance, payments, and results. Users can read, mark as read, and delete notifications from their inbox. School admins can also configure automated message reminders.

## School Admin, Teacher, Student

| Action | Result |
|--------|--------|
| Click the notification bell in the header. | A notification panel opens showing recent items. An unread count badge appears on the bell when you have unread notifications. |
| Search notifications on the full notifications page. | The inbox list filters to matching items. |
| Filter by All, Unread, or category pills. | The list shows only notifications matching the selected filter. |
| Click a notification. | The notification is marked as read. |
| Click **Mark all as read**. | All unread notifications are marked read. The button is disabled when there are none unread. |
| Delete a notification using the trash icon. | The notification is removed from your inbox. |

## School Admin — Message reminders

| Action | Result |
|--------|--------|
| Open **Notifications**, go to the **Settings** tab, and click **Add New**. | A dialog opens to create a message reminder. |
| Create, edit, or delete a message reminder. | Success messages appear and the reminder list refreshes. |

## Empty, error, and blocked states

- Inbox shows “No notifications available” when empty.
- Message reminders show “No Message Reminders available, click ‘Add New’ to create one” when none exist.
