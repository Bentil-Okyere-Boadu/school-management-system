# Admissions

**Who can use this:** School Admin, Public  
**Where:** School Admin → Admissions; public applicants use the school’s admission form link

## Overview

Admissions lets prospective families apply to a school through a multi-step public form. School admins review applications, change their status, send interview invites, and track admission analytics.

## Public applicant

| Action | Result |
|--------|--------|
| Open the school’s admission form and complete **Step 1** — student information, desired class, and required documents. | You can proceed once all required fields are valid. |
| Complete **Step 2** — add one or more guardians with their details. | You can proceed once each guardian’s information is complete. |
| Complete **Step 3** — languages spoken and prior school history (if applicable). | You can proceed once the step is valid. |
| Review all entered information on **Step 4** and click **Submit Application**, then confirm. | A success message appears. The school receives an admission notification. You are redirected to a confirmation page stating the application was submitted and that email follow-up will follow. |

## School Admin

| Action | Result |
|--------|--------|
| Open **Admissions** and click **Go to Admissions Form** or copy the form link. | The public form opens in a new browser tab, or the link is copied to your clipboard with a confirmation message. |
| Open the **Admissions Analytics** tab. | You see read-only metric cards and charts showing admission trends and statistics. |
| Open the **Admissions List** tab. Search, filter by status, or change pages. | The application list updates to match your filters. |
| Change an application’s status to Accepted, Rejected, Waitlisted, or Mark completed from the status menu. | A success message appears and the list refreshes with the new status. |
| Select **Send Interview Invite** from the admissions list status menu. | A Calendly popup opens in your browser (even if no scheduling URL is configured). When you book an event in that popup, the application status changes to Interview Pending. The applicant does not schedule from this popup. |
| Open an application’s detail page. Change status, or click a submitted document. | Status changes show a success message and refresh the page. Documents open or download in a new tab. |
| On the detail page, select **Send Interview Invite**, enter an interview date and time, and submit. | An interview invitation email is sent to the applicant. This path does not open Calendly. |
| Archive an application from the row menu. | A confirmation dialog appears. After confirming, a success message appears and the list refreshes. |

## Empty, error, and blocked states

- The admissions list shows “There are no admissions at this moment” when empty.
- Copy-link failures show an error message.
- Public form steps block **Continue** until required fields are filled.
