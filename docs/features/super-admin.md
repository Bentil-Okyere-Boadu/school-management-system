# Super Admin

**Who can use this:** Super Admin  
**Where:** Super Admin → Dashboard, Schools, Users

## Overview

Super Admin is the platform-level console for managing all schools on the system. Super admins view platform-wide statistics, configure payment credentials per school, invite school admins, and manage user accounts across the platform.

## Dashboard

| Action | Result |
|--------|--------|
| Open the **Dashboard**. | Stat cards show total schools, teachers, students, and average attendance rate. A bar chart displays platform-level data. |
| Search users in the “Recently Added Users” table. | The table filters to matching users. |
| Resend an invitation from a row menu. | A success message confirms the invitation was resent. |
| Archive or unarchive a user. | A confirmation dialog appears. After confirming, a success message appears and the table refreshes. |
| Click **View more**. | You navigate to the full Users page. |

## Schools

| Action | Result |
|--------|--------|
| Open **Schools** and search by school name. | The school card grid filters to matching schools. |
| Click a school card. | You open the school detail page with tabs for School Settings, Configuration, Hubtel Merchant, Profile, and People. |
| View School Settings, Configuration, or Profile tabs. | School information displays in read-only mode (logo, fee structure, grading system, class levels, admission policies, academic calendar, contact fields). |
| Open the **People** tab. | A read-only list of users belonging to that school appears. |
| Configure Hubtel Merchant credentials (see [payments.md](./payments.md)). | Payment provider settings are saved or removed for that school. |

## Users

See [users.md](./users.md) for inviting and managing platform users.

## Empty, error, and blocked states

- User and school lists show loading indicators while data loads.
- Most school detail tabs are read-only except Hubtel Merchant configuration.
