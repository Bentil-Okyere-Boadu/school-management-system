# Grading

**Who can use this:** School Admin, Teacher  
**Where:** School Admin → Scores (assignment submissions); Teacher → Grading; Teacher → Subjects → Assignments → Grade

## Overview

Grading covers entering term scores (class and exam marks) for students and reviewing assignment submissions. Teachers enter scores per subject and term. School admins view assignment submission status but do not enter term scores directly — that happens on the Teacher Grading page.

## Teacher — Term scores

| Action | Result |
|--------|--------|
| Open **Grading** and search for a class, then click a class card. | You open the per-class grading table. |
| Select a subject and academic term. | Student score rows load for that subject and term. |
| Enter class and exam scores for students and click **Save Changes**. | A success message appears and scores are saved. |
| Toggle **Show archived students**. | Archived student rows appear with score inputs disabled. |
| Try to save when results are submitted or locked by the school admin. | Save is disabled and a status badge indicates why changes cannot be made. |

## Teacher — Assignment grading

See [assignments.md](./assignments.md) for creating assignments and grading individual submissions.

## School Admin

| Action | Result |
|--------|--------|
| Open **Scores** and view an assignment’s **Submitted** and **Pending** tabs. | You see read-only tables of which students have submitted work and which are still pending. |

## Empty, error, and blocked states

- Grading inputs are disabled when class results are submitted or admin-locked.
- Missing grades are listed in a dialog when a teacher tries to submit class results from the Classes page.
